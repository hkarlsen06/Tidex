# Icon Sources

All SVGs in this folder are exported from the Tabler Icons set. When you need a new asset:

1. Grab the 24x24 outline or filled variant from https://tablericons.com/.
2. Drop the optimized SVG in this directory (keep names kebab-cased).
3. If you prefer a React component, import it from `@tabler/icons-react` and see `docs/assets.md` for more tips.

Keeping everything Tabler-based ensures the UI stays visually consistent.

## 🎨 Key Patterns You'll See

### Semantic Color Tokens

All generated code uses semantic tokens:

```typescript
// You'll see this:
className="bg-surface-primary text-text-secondary border-border"

// Never this:
className="bg-slate-900 text-gray-400 border-zinc-700"
```

### Two-Tier Components

All components follow this pattern:

```typescript
// Base (components/ui/button.tsx) - generated by shadcn
export const Button = ...

// Wrapper (components/app/Button.tsx) - generated by scaffold skill
import { Button as BaseButton } from '@ui/button';
export function Button({ className, ...props }) {
  return <BaseButton {...props} className={cn(...)} />;
}

// Usage - always import wrapper
import { Button } from '@appui/Button';
```

### Server-Side Data Loading

All routes follow this pattern:

```typescript
// page.tsx (Server Component)
export default async function Page() {
  const data = await getData(userId); // Fetch + compute
  return <View data={data} />;        // Pass to client
}

// View component (Client Component)
'use client';
export function View({ data }) {
  return <div>{data.precomputedValue}</div>; // Just render
}
```

## 🛠 Common Workflows

### Adding a shadcn Component

1. **Add shadcn component:**
   ```bash
   npm dlx shadcn@latest add dialog
   ```

2. **Scaffold app wrapper:**
   ```
   /scaffold
   ```

   ```typescript

   ```

## 🆘 Troubleshooting

### Issue: "Cannot find module '@appui/Component'"

**Cause:** App wrapper wasn't created

**Fix:**
```
/scaffold
"Create an app wrapper for the [component] component"
```

---

### Issue: "Hydration mismatch"

**Cause:** Client/server rendering mismatch

**Fix:** Check for:
- Date formatting (use server-computed dates)
- Random values (compute server-side)
- localStorage (only access in useEffect)

---

### Issue: "Expected authenticated user" error

**Cause:** Auth check failing

**Fix:** Ensure middleware redirects work:
```typescript
// middleware.ts should protect /app routes
```

---

### Issue: Type errors in components

**Cause:** Types not exported/imported

**Fix:**
```typescript
// Data loader
export type MyData = { ... };
export async function getMyData() { ... }

// Component
import type { MyData } from '@/app/(app)/[route]/_data/getMyData';
```

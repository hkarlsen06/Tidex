Πόσο αξίζει πραγματικά εκείνη η έξτρα βάρδια;

Μια αργή βραδινή βάρδια, μια Κυριακή, λίγες ώρες υπερωρίας. Οι ώρες μπορεί να φαίνονται παρόμοιες στο ημερολόγιό σας, αλλά η αμοιβή μπορεί να διαφέρει πολύ. Το Tidex σάς βοηθά να δείτε πόσα θα βγάλει η δουλειά σας, πριν από την ημέρα πληρωμής.

ΔΕΙΤΕ ΤΙ ΣΥΝΥΠΟΛΟΓΙΖΕΤΑΙ ΣΤΗΝ ΑΜΟΙΒΗ ΣΑΣ
Προσθέστε τις βάρδιές σας και αφήστε το Tidex να υπολογίσει τα εκτιμώμενα κέρδη σας με βάση την ωριαία αμοιβή, τα επιδόματα, τις υπερωρίες και τους κανόνες διαλειμμάτων. Δείτε την ανάλυση πίσω από το σύνολο, ώστε να ξέρετε από πού προέρχονται τα χρήματα.

ΔΕΙΤΕ ΤΙ ΑΛΛΑΖΕΙ ΜΙΑ ΕΠΙΠΛΕΟΝ ΒΑΡΔΙΑ
Βάλτε μια επερχόμενη βάρδια στο ημερολόγιό σας και δείτε πώς επηρεάζει τα εκτιμώμενα κέρδη σας. Αποκτήστε πιο ξεκάθαρη εικόνα για τον μήνα που έρχεται όταν αποφασίζετε αν αξίζει να αναλάβετε περισσότερες ώρες.

ΠΑΝΩ ΑΠΟ ΜΙΑ ΔΟΥΛΕΙΑ; ΚΡΑΤΗΣΤΕ ΤΑ ΟΛΑ ΜΑΖΙ
Κρατήστε τις βάρδιες και τις ρυθμίσεις αμοιβής για κάθε δουλειά σε ένα μέρος. Παρακολουθήστε τις ώρες και τα κέρδη σας με τον χρόνο, χωρίς να συνδυάζετε ξεχωριστές σημειώσεις και υπολογισμούς.

ΕΧΕΤΕ ΚΑΤΙ ΓΙΑ ΝΑ ΣΥΓΚΡΙΝΕΤΕ ΜΕ ΤΟ ΕΚΚΑΘΑΡΙΣΤΙΚΟ ΣΑΣ
Κρατήστε το δικό σας αρχείο για τη δουλειά που έχετε κάνει. Εξαγάγετε βάρδιες σε PDF ή CSV όταν θέλετε να συγκρίνετε ώρες, να ελέγξετε μια διαφορά ή να μοιραστείτε μια αναφορά.

Ο χρόνος σας αξίζει να παρακολουθείται. Ξεκινήστε με την επόμενη βάρδιά σας.

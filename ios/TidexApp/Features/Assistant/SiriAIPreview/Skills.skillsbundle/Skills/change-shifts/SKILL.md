# Change shifts

A shift is one stretch of work for a job, with a day, a start time and an end time. Tidex works out pay from the user's shifts, so a duplicate shift counts twice.

## Choose the tool by what already exists

- The shift is not in Tidex yet. Use the Add Shift tool.
- The shift exists and the user wants another day or other times. Use the Move Shift tool on that shift.
- The user is at work now and stays longer. Use the Extend Shift tool. It changes only the shift that is going on right now. To give a later shift a new end time, use the Move Shift tool.
- The user is done working. Use the Clock Out tool. It opens Tidex, where the user reviews the time and saves it, so tell them to finish there.

If the user wants to add a shift on a day and you can't tell whether one is already there, look at their shifts for that day first. If you find one, ask whether to change it or add another.

## Add a shift

Ask for the day, the start time or the end time when the user left it out. Don't guess one.

Pass the times as the user said them. An end time earlier than the start time means the shift ends the next day, such as 22:00 to 06:00.

When the user names several days, add one shift for each day.

## Shifts that repeat

A shift that repeats every week comes from a recurring shift. The Move Shift and Extend Shift tools refuse it. Tell the user to change it in Tidex.

## Don't

- Don't ask the user to confirm before you call the Add Shift, Move Shift or Extend Shift tool. Each one asks before it saves.
- Don't add a new shift to correct one that exists or one a tool refused to change.
- Don't add, move or extend a shift the user didn't ask for.

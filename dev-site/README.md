# Developer Portfolio Site

Personal portfolio website for Hjalmar Kristensen showcasing development projects and skills.

## Tech Stack

- **Framework**: Next.js 16
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Components**: shadcn/ui (Radix UI)
- **Internationalization**: Norwegian & English

## Development

```bash
# Install dependencies
npm install

# Run dev server (port 3002)
npm run dev

# Build for production
npm run build

# Serve production build
npm start
```

## Features

- Multi-page portfolio with navigation
- Internationalization (Norwegian/English)
- Dark mode design
- Responsive layout
- Project showcase (Tidex)
- Contact page with email CTA
- Static export ready

## Deployment

This site is configured for static export and can be deployed to:
- Vercel
- Netlify
- Any static hosting service

The build output goes to the `out/` directory.
